## 1. 범위

**만드는 것**: 생산 루틴 카드 생성·체크·취소, 오늘 루틴(PC·휴대폰), 완료율 14일 표, 템플릿 관리, 홈 카드, 수동 생성 버튼, 어제 미완료 표시, 로컬 읽기 모드.
**안 만드는 것**: 칸반·월간·슬랙·품번 연결·다른 파트·pg_cron·과거 체크·캘린더 화면·계정 생성·'80% 2주 연속' 판정 줄(2단계에서 정의).

## 2. 핵심 규칙 (순수 함수, `utils/dash_routine.py`)

- `shift_slot(now_utc) → (work_date, shift)`: KST 변환 후 `07:30 ≤ t < 19:30 → (D,'day')`, `t ≥ 19:30 → (D,'night')`, `t < 07:30 → (D−1,'night')`. 모든 날짜 계산은 이 함수만(`date.today()`·naive now 금지 — 정적 검사).
- `is_off(d, cal)`: `day_type(d, cal) == 'OFF'`. `is_pre_holiday(d, cal)`: `day_type(d+1, cal) in ('OFF','HOLIDAY')`. `cal` = `work_calendar` → `{cal_date: day_type}`.
- `plan_template_ids(templates, work_date, shift, cal) → list[int]`: 활성 + shift 일치 + (`always` or `pre_holiday and is_pre_holiday`) + **`assignee_user_ids` 비어 있지 않음**(D2/H4); `is_off(work_date)` 면 빈 목록. 제외된 '담당자 미지정' 수도 반환(관리자 caption 용).
- `can_write(card, slot)`: `(card.work_date, card.shift) == slot` (D6/H3). 핸들러가 호출 시점에 `shift_slot(now)` 를 **다시 계산**.
- `completion(cards) → float|None`: 분모 = 카드 수, 0 → None. `slot_state(date, shift, cards, cal)`: 휴무 / 미생성 / 진행중 / 종료(표에서 구분 표시, M4).
- `prev_slot(slot)`: 같은 shift 의 전날.
- `new_template_code(part_code, shift)`: `f"{part_code}_{shift}_{uuid4().hex[:8]}"`(시드 `prod_day_NN` 와 충돌 없음, 충돌 시 1회 재생성, M6).

생성 표(D4): 월~목 주○야○(pre_holiday 는 다음 날 HOLIDAY 일 때) / 금 주○야○(다음 날 토=SATURDAY → pre ✕, 토가 HOLIDAY 면 ○) / 토 주○야○(pre ○, 다음 날 일 OFF) / 일 ✕ / HOLIDAY 주○야○(근무일 취급).

## 3. 생성·체크·취소 흐름

- **로컬 읽기 모드**(D7/B1): `_dash_readonly = bool(secrets.auth.disabled)`. True 면 생성 RPC·체크·취소·템플릿 저장·수동 생성 전부 **핸들러 첫 줄에서 차단**(버튼은 비활성 + 배너). 테스트로 "읽기 모드에서 모든 쓰기 0".
- **생성**: 오늘 루틴 진입 시(현재 슬롯 표시 중일 때만) `ids, n_excluded = plan_template_ids(...)` → 빈 목록이면 RPC 호출 없음("휴무일" 또는 "담당자 미지정 N개 제외") → `db.rpc("dash_generate_cards", {p_work_date, p_shift, p_template_ids})` → 관리자 caption "생성 N · 이미 있음 M". RPC 예외(`RpcUnavailable/Rejected/Transport`)는 flash 안내 + 재조회, 재시도 없음. 수동 생성 버튼(관리자): 같은 경로 + `click_guard("dash_gen")`.
- **체크**: 카드별 `st.button("완료", key=f"dash_done_{id}", use_container_width=True)`(48px). 핸들러: 읽기 모드 차단 → `click_guard(f"dash_chk_{id}")` → `u = current_user().get("username")`(빈 값 거부, H2) → 권한 `u in card.assignee_user_ids or role=='admin'` → `can_write(card, shift_slot(now))` → `n = db.update_count("dash_cards", f"id=eq.{id}&status=eq.todo", {"status":"done","completed_by":u,"completed_at":now_utc_iso})` → `n==1`: 로그 `insert("dash_card_activity",[{card_id,user_id:u,action:'done',from_value:'todo',to_value:'done'}])`(예외 시 flash warning + `log_error`, 상태는 유지) → rerun. `n==0`: 최신 행 `fetch(cache=False)` → flash "OOO 이 HH:MM 완료함". `n==-1`/예외: flash "저장되지 않았습니다 — 새로고침 후 다시" + 재조회.
- **취소**: done 카드에 [취소] → `confirm_gate(f"dash_undo_{id}", "…", )`(**카드별 키**, H5) → 확인 당시 `completed_at` 을 세션에 보관 → `update_count("dash_cards", f"id=eq.{id}&status=eq.done&completed_at=eq.{그 값}", {"status":"todo","completed_by":None,"completed_at":None})` → `n==0` 이면 "상태가 바뀌어 다시 확인하세요" 후 게이트 초기화 → 로그 `undo`(from 'done' to 'todo'). 권한·슬롯 검사는 완료와 동일. `click_guard(f"dash_undo_{id}")`. `st.checkbox` 금지.
- **flash**: 메뉴 개편의 `nav_go(flash=)` 와 같은 세션 flash 로 경고를 다음 실행에 보존(M1).
- **권한**: 오늘 루틴 열람 전원. 완료율·템플릿 관리 = `_subs_for` 로 작업자에게 숨김 + **본문 분기 안 `role=='admin'` 재검사**(아니면 오늘 루틴으로 보정, 세션 키·`nav_sc_dash` 주입 모두). 템플릿 저장 시 담당자 목록은 문자열·중복·빈 원소·auth_users 미존재 검증.
