Source of Truth 변동 없음. 수량 불변식(`received − presched = Σ delivered`)은 payload 산출 규칙 그대로. |
| 5 | 영향 파일 | `streamlit_app.py` 9729~9975(payload 조립으로 재구성 — 계산 코드는 유지하고 쓰기 호출만 모음), `db.py`(`rpc`), `tests/test_shipment_revision_flow.py`·확정 테스트(RPC 경로: payload 내용 검증 / 폴백 경로: 기존 테스트 그대로), `supabase/migrations/069_confirm_shipment_rpc.sql`. |

## 실행 순서(승인 후)

1. `db.py` `rpc`/`log_error` + 067 migration + 코드 → 전체 pytest → Reviewer(Data·QA) → 푸시.
2. 068 migration + 채번 코드 → 전체 pytest → 푸시(입고·투입이 없는 시간).
3. 069 migration + 확정 코드 → 전체 pytest → Reviewer(Data·QA, 필요 시 UX) → 출고 없는 시간에 푸시 → 첫 확정 1건 사용자 확인.

각 단계는 별도 커밋. 어느 단계든 BLOCKER 가 남으면 그 단계에서 멈추고 보고한다(AGENTS.md 14절).
