## 1. 원칙

- 토스 스타일(2026-08-12 사용자 확정): 테두리 없는 흰 카드 + 은은한 그림자, 회색면 보조 버튼, 파란 주 버튼, 상태는 색·배지로만(이모지 금지).
- 화면당 **주 버튼은 하나**. 위험 버튼은 빨간 글자. 확인 게이트의 [실행 확정]은 위험색.
- 직원 화면에 절차 설명 caption 을 두지 않는다. 설명은 `help` 툴팁. 성공·실패는 **flash**(다음 실행 제목 아래)로 — `st.success` 뒤 `st.rerun` 금지.
- 모든 색은 토큰(`var(--…)`)으로. CSS·파이썬·AgGrid JS 어디서든 hex 직접 쓰기 금지(AgGrid 는 `_TOSS_GRID_CSS` 한 곳에서 토큰 값을 복제).
- 숫자는 `tabular-nums`, 우측 정렬.

## B. 화면별 명세

### B-1 수주 관리 › 수주 입력
블록 순서(위→아래): PageHeader(탭: 수주 입력·수주 목록·납품 스케줄, 우측 링크 "수주 목록 보기") → **SummaryStrip**(미납 수량·진행 수주·납기 지연(`--warn2`)·이번 달 수주 + 칩 "제품 확인 필요 n" `--warn-bg`, "단가 변경 n" 회색 — 칩 클릭 = 해당 패널 expander 열기) → **입력 카드**(제목 "입력" + 우측 입력 방식 segmented[파일 업로드|수기 입력]; 업로드 = 드롭존 1개 + 지원 양식 1줄; 수기 = 헤더 폼 2열 + 품번 검색 + [추가]) → **결과 카드**("미리보기 · 거래처 · 발주번호 · n줄" + 우측 배지 '파싱 완료'/'품번 확인 n'; 표 열 = #·우성 품번·품명·수량·납기·단가·상태배지; 375 = ListRow(품번 / 납기·단가 / 수량 / 배지) + "전체 열 보기" 링크) → **ActionBar**(우 "합계 n EA · 품번 확인 n줄은 저장 뒤 '제품 확인 필요'에서" + [수주 저장 (n줄)]). [초기화]는 미리보기 카드 머리 우측(위험색 + 2단계). 저장 성공 = flash + 업로더 비움, 실패·부분 실패 = 결과 카드 하단 경고(r2 D1·D7·D10).
- 제품 확인 필요·단가 변경 패널은 **expander 로 접어** 띠 아래에 둔다(현재 3세부 공통 패널 5589~6188 → 수주 입력에서만 접힘, 목록·스케줄은 현행).
- 수기 입력 결과 카드 = 담긴 품목 ListRow + 행 [삭제](위험색, 375 에서도 한 줄) + 머리 우측 [초기화](위험색 + 2단계) — 375 수기 품목 UI 이월(U1b) 여기서 해결. 합계 표기 "n원 (부가세 별도)"(r2 D10).

### B-2 구매 관리 › 발주서 작성
PageHeader(탭 5개, 우측 = "작업 방식" 라벨 + segmented[부족 자재에서 담기|발주서 편집]; 375 는 탭 아래 별도 줄) → **Stepper** ① 거래처 ② 품목 담기 ③ 발주서 → **입력 카드 = 현재 단계만**: ①은 그룹 radio + 거래처 select + 신규 거래처 expander; ② "부족 자재 · 거래처 · n개(합)" 표(체크·자재명·규격·필요량·재고·미입고 발주·부족분 `--warn2` 700) + 거래처 미지정 안내는 배지 1개로; ③ 발주 헤더(발주일·납기·메모) → **결과 카드** "담긴 품목 n · 발주 수량은 표에서 수정" + 우측 [전체 비우기](prefill 이 있으면 [모두 초기화], 위험색 + 2단계); ③ 단계 머리 보조 = "n개 · 거래처 — {이름}"(r2 D5); 표 = 자재명·발주 수량(입력)·단위·단가·금액·[삭제] → **ActionBar**(좌 [① 거래처 바꾸기] 또는 [② 품목으로] — prefill 경로 포함 항상(r2 D2), 우 "합계 n원 (부가세 별도)"(③ 은 "거래처 — {이름} · 합계 …") + [③ 발주서로 (n품목)] / ③단계에서는 폼의 [발주서 만들기]). 거래처 조회 실패·빈 목록이면 ① 카드를 보이고 ActionBar 는 그대로(r2 D3).
- `st.info/warning` 6종(14400~14630)은 **배지·한 줄 보조 설명·help** 로 치환, 남는 경고는 1개.
- 보류 prefill 안내는 한 줄 보조 설명, [모두 초기화]는 담긴 품목 카드 머리 우측(위험색 + 2단계) — ActionBar 좌측 아님(r2 D1).

### B-3 출고 관리 › 출고 등록
PageHeader(탭 4개, 우측 링크 "작성중 전표 n건 보기") → **입력 카드** "출고 리스트 담기": 1줄 grid(회차 기준일·납품일·검색·지연 회차 포함 체크; 375 = 날짜 2열 + 검색 + 체크) → **결과 카드** "미납 회차 · 기준일 이하 n건 · 선택 n" + 우측 배지(지연 n `--danger-bg`, 완성 재고 부족 n `--warn-bg`); 표 열 순서 = **선택·품번·출고(입력 80px)·잔량·완성 재고·납기·거래처·수주번호·구분**(r2 D4 — 편집할 열을 앞으로). 완성 재고 조회 실패 = '미확인'(빈칸, 부족 계산 제외, 카드 경고 1줄), LOT 1,000행 페이지 반복, 부족 = 품번별 누적 잔량 vs 완성 재고(r2 D6). 셀 색·구분 배지·375 ListRow 는 data_editor 한계로 U4; 카드 하단 보조 설명 "등록 시점에는 차감하지 않습니다 — 확정 때 한 번에" → **ActionBar**(좌 [선택 해제]/[전체 선택] 토글(비파괴), 우 "선택 n건 · n EA · 납품일" + [출고 등록 — 전표 생성 (n EA · n건)]).
- 등록 뒤 flash + toast(U1b) 유지, [출고 전표 열기] 는 flash 의 action 버튼.

## C. 허용 오차·제약(명세 대비 차이로 보지 않는 것)
- 위젯 모양(체크박스·date_input·number_input)은 Streamlit 기본, 간격 ±4px, 배지 높이 22±2.
- ActionBar 는 화면 하단 고정이 아니라 섹션 끝(§7 제약). 375 에서 주 버튼까지 스크롤이 길면 **결과 카드 위에 요약 1줄 반복** 허용.
- AgGrid 표(`toss_grid`)는 375 에서 ListRow 가 아니라 열 숨김으로 대체.
- 사이드바 세부 버튼 제거로 `nav_s_*` 키를 찾는 테스트는 **탭 바(`nav_sc_*`) 기준으로 재작성**; `nav_sub` 상태·`_NAV_KEEP`·`nav_go(main, sub)` 는 불변.
- 홈·업무 루틴·관리자 화면은 PageHeader 탭 바 상시 적용만 받고 블록 재배치는 범위 밖(U4).
- **실패 안내**(조회 실패·알 수 없는 양식·회차 조회 실패)는 st.warning/st.error 그대로 — "안내 축소"(st.info/warning → 한 줄 보조 설명) 대상이 아니다(r2 D8).
- **문구 표준**(r2 D10): 합계 "n원 (부가세 별도)", 미매칭 품목 = '품번 확인', 단가 패널·칩 = '단가 변경', 주 버튼 괄호 (n줄)/(n품목)/(n EA · n건).
